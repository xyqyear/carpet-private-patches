新增 `fixBlueMap`，修复 Carpet 假玩家退出后 BlueMap 仍显示在线玩家的问题。

- 通过 Carpet 退出回调补齐 Fabric DISCONNECT，保留目标版本已有的 JOIN，避免重复登录通知。
- 默认关闭，使用 `/privatepatches setDefault fixBlueMap true` 持久开启。
- 与 `playerRetentionMemoryLeakFix` 独立控制。新规则会顺带结束网络会话；原版地图旧引用清理仍由内存规则控制。
- 无新增生产 Mixin、BlueMap 依赖或玩家缓存。客户端无需安装。
- 同一 JAR 支持 Minecraft 26.2、26.3，依赖 Java 25、Carpet 和 Fabric API。

发布验证包含七组依赖组合的长循环和两个真实客户端测试，其中 BlueMap 5.28 集成覆盖真实玩家集合、两个开关的四种组合、事件去重、同 UUID 重连和持久化。客户端覆盖普通玩家连接、退出、重生和换维度。

开启后作用于后续退出，包括已经在线的假玩家；不会为已经离线的历史实例重放退出事件。该规则通知所有 Fabric 退出订阅者，不仅是 BlueMap。

实际发布验证记录与被测 JAR 校验和见附件 `compatibility.json` 和 `SHA256SUMS`。
