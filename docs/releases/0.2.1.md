两项补丁规则统一使用 `/carpet` 和世界目录下的 `carpet.conf`。

```text
/carpet setDefault playerRetentionMemoryLeakFix true
/carpet setDefault fixBlueMap true
```

- 移除独立设置管理器和 `/privatepatches` 命令，规则翻译使用 Carpet 主命名空间。
- 补丁逻辑和默认关闭状态不变，同一 JAR 支持 Minecraft 26.2、26.3。
- 配置实机测试检查规则归属、翻译、持久化文件、原有 Carpet 设置保留和重启加载。

升级后旧 `privatepatches.conf` 不再读取，也不会被自动修改。请根据原有配置，用 `/carpet setDefault <规则名> <原值>` 重新保存两项规则。
