服务器自用的 Carpet 补丁集合，首次正式发布。

- `playerRetentionMemoryLeakFix`：释放退出 Carpet 假玩家的 Fabric 网络注册记录，并清理已加载地图中失效的玩家引用。
- 两条修复共用一个规则，默认关闭，支持运行中切换与 `setDefault` 持久化。
- 同一 JAR 支持 Minecraft 26.2、26.3；依赖 Java 25、Carpet、Fabric API，客户端无需安装。
- 发布验证包含五组依赖组合的各 1,000 次假玩家循环、配置重启、Igny 实际退出路径，以及两版真实客户端连接、重生、换维度测试。

开启：`/privatepatches setDefault playerRetentionMemoryLeakFix true`。

关闭期间已经泄漏的网络记录需重启释放；地图清理每 100 tick 执行一次。详细背景、行为边界和测试方法见仓库文档。

`v0.1.0` 的发布被云端客户端虚拟显示配置问题阻止，没有发布附件。此版本配置 EGL 以支持 Minecraft 26.3 的客户端实机测试，并在服务端测试失败时及时结束客户端。补丁行为不变。

附件 `compatibility.json` 记录本次实际验证结果，`SHA256SUMS` 对应同一份被测试的 JAR。
